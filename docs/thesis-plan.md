# 論文計画(thesis plan)

博士論文の骨格を一枚にまとめます。研究と章の一覧・並び・状態の正本は `research.json`、文章の正本は原稿(`draft/`)、
発表論文の一覧の正本は `draft/frontmatter/publications.tex` です。ここには要約・ラベル・値のキー・bib キーだけを書き、
同じ文章を二重に持ちません。8000字以内(テストが検査します)。

## 全体の一貫性チェック

`review-thesis` スキルはこの一覧で論文全体を確かめます。章を大きく直したときと、版を送る前に上から見ます。

- [ ] 各 RQ に結論の章(`ch:conclusion`)が答え、根拠の章を `\cref` で示している。
- [ ] 序論の研究課題と章の構成の説明が、上の表・`research.json`・`draft/main.tex` の章の並びと一致している。
- [ ] 和英の要旨と結論の数値が `\val{…}` で章と同じ値を読んでいる(手で書いた数値が無い)。
- [ ] 各貢献に根拠(章・図表・値・論文)があり、撤回・訂正された結果(`docs/guardrails.md`)に頼っていない。
- [ ] 各研究の章の Summary が、答えた RQ と次の章へのつながりを述べている。
- [ ] `frontmatter/publications.tex`、各章の前書き(出版の状況・著者の貢献)、`research.json` の `paper`・`paper_status` が一致している。
- [ ] 写した図・表の転載の許諾と、出版社の再利用の規程を確かめてある。
- [ ] 用語・記号・略語が `notation.tex`・略語一覧と一致し、章ごとに定義が揺れていない。
- [ ] この計画と原稿が食い違っていない(食い違ったら原稿に合わせてここを直す)。
