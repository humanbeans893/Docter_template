# 論文計画(thesis plan)

博士論文の骨格を、ID と対応関係だけで一枚にまとめます。文章そのものの正本は原稿(`draft/`)で、
発表論文の一覧の正本は `draft/frontmatter/publications.tex` です。ここには要約・ラベル・図表や値の名前・
bib キーだけを書き、同じ文章を二重に持ちません。8000字以内を保ちます(行数ではなく文字数。`tests/test_repo_structure.py` が検査します)。

## 段階の定義

- 研究段階: 構想 → データ整備 → 解析 → 検証 → 執筆 → 完了
- 執筆状況: 構想 → 骨子 → 初稿 → 推敲済 → 指導教員確認済 → 確定

## 全体の一貫性チェック

`/review-thesis` はこの一覧で論文全体を確かめます。章を大きく直したときと、版を送る前に上から見ます。

- [ ] 各 RQ に、結論の章(`ch:conclusion`)が答えを出し、その根拠の章を `\cref` で示している。
- [ ] 序論の研究課題と章の構成の説明が、上の表と `draft/main.tex` の章の並びに一致している。
- [ ] 和英の要旨と結論の数値が `\val{…}` で章と同じ値を読んでいる(手で書いた数値が無い)。
- [ ] 各貢献に根拠(章・図表・値・論文)があり、根拠が撤回・中止・置き換え・進行中の実験に頼っていない。
- [ ] 用語・記号・略語が `notation.tex`・略語一覧と一致し、章ごとに定義が揺れていない。
- [ ] 各スタディの章の「Chapter Summary」が、答えた RQ と次の章へのつながりを述べている。
- [ ] `frontmatter/publications.tex` と、各章の冒頭の出版情報・著者の貢献が一致している。
- [ ] R3 の生成物(`make check` の I3)を指導教員と確かめ、ライセンス・転載の許諾がそろっている。
- [ ] この表と原稿が食い違っていない(食い違ったら原稿に合わせてこの表を直す)。
