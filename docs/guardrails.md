# 繰り返さないこと

この論文で繰り返してはいけない失敗と、撤回した主張を記録します。毎セッションの最初に読むので1件1行にし、経緯は `docs/research-log.md` か研究リポジトリの記録(`<repo>@<sha>:<path>`)に書いてリンクします。8000字以内(テストが検査します)。起きたその場で行を足します。

## 博士論文で起きやすいこと(一般則。この論文に合わせて削ってよい)

- 結果の数値を本文に打ち込まない。要旨・結論・図表の説明も `\val{…}` で `projects/<id>/values.tex` の値を読む。
- 研究リポジトリや `external/` の図を直接読み込まない。コミットから `projects/<id>/` に写す(E10)。
- 図を加工・再描画したり、数値を計算し直したりしない。欠けたものは研究リポジトリで作ってもらう。
- 元(`<repo>@<sha>:<path>`)を書かずに図・表・数値を写さない。未コミットの変更がある作業ツリーから写さない。
- ある研究の結果が変わったら、和英の要旨・結論・`docs/thesis-plan.md` も同じ作業で直す。章だけ直して終えない。
- 論文の章を貼り付けたままにしない。総合序論との重複を削り、博士論文の章として書き直す。
- 原稿を縮めるときに、主張の限定(条件・例外)を一緒に落とさない。
- 図の見え方やページの崩れを、ログだけで「問題なし」と報告しない。PDF を開いて確かめる。
- `draft/` の中で `lualatex` を手で実行しない(残った `.aux`・`.bbl` が黙って読まれる)。
- 書誌を推測で作らない。DOI で原典を確かめてから `reference.bib` に入れ、`verified` の欄を付ける。
