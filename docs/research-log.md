# 研究ログ

解析・執筆のセッションの記録です。**新しいエントリほど上**に置きます。`research-log` スキルで追記できます(手で書いても構いません)。

- 実験の結論の正本は各実験の `summary.md`(経緯は `README.md`)です。ここには経緯と判断を書き、結果はリンクで示します。
- 繰り返さない行き止まりは `guardrails.md` にも1行で書きます。撤回・訂正・置き換えは `AGENTS.md` の「実験」の手順で `summary.md` と索引に書きます(撤回と、古い主張がすでに外に出た訂正・置き換えは `guardrails.md` にも)。
- 影響の大きい決定は `decisions/` の意思決定記録にして、ここからリンクします。

エントリの書式:

```markdown
## YYYY-MM-DD — 短い題

- **目的**: 何をしようとしたか
- **やったこと**: 実際にやったこと(実行したスクリプト・実験 `projects/<study>/experiments/NNN_<slug>`・生成した図表・関連コミット)
- **判断**: 下した判断とその理由(重要な決定は decisions/ の記録へリンク)
- **行き止まり**: うまくいかなかったことと原因(繰り返さないものは guardrails.md にも)
- **次**: 次にやること
```
