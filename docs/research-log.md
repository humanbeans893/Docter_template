# 研究ログ(Research Log)

解析・執筆セッションの記録。**新しいエントリほど上**に置く。`/research-log` スキルで追記できる(手書きももちろん可)。日本語・英語どちらでもよい。

エントリの書式:

```markdown
## YYYY-MM-DD — 短いタイトル

- **Goal**: 何をしようとしたか
- **Done**: 実際にやったこと(実行したスクリプト・生成した図表・関連コミット)
- **Decisions**: 下した判断とその理由(重要な決定は docs/decisions/ の ADR にもリンク)
- **Dead ends**: うまくいかなかったことと原因(将来の自分への財産)
- **Next**: 次にやること
```
