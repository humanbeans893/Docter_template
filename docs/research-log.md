# 研究ログ

論文をまとめる作業の記録です。**新しいエントリほど上**に置きます。`research-log` スキルで追記できます(手で書いても構いません)。

- 実験の結果と判断は研究リポジトリの記録が正本です。ここには論文をまとめる上での経緯と判断を書き、研究リポジトリは `<repo>@<sha>:<path>` でリンクします。
- 繰り返さない行き止まりと撤回した主張は `guardrails.md` にも1行で書きます。
- 影響の大きい決定は `decisions/` の意思決定記録にして、ここからリンクします。

エントリの書式:

```markdown
## YYYY-MM-DD — 短い題

- **目的**: 何をしようとしたか
- **やったこと**: 実際にやったこと(取り込んだ研究 `projects/<id>/`・`<repo>@<sha>`、直した章、関連コミット)
- **判断**: 下した判断とその理由(重要な決定は decisions/ の記録へリンク)
- **行き止まり**: うまくいかなかったことと原因(繰り返さないものは guardrails.md にも)
- **次**: 次にやること
```
