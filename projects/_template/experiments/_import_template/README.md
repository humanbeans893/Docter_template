## 方法

- パラメータ: `params.py`(取り込み元 `SOURCE_DIR`、マニフェスト、照合の基準値。`PARAMS` にまとめ、`out/params_used.json` に残る)
- 順序: 入力の照合 → `out/` での作り直し → 既報の数値との照合 → 生成物を書く。照合が通らなければ実行は失敗し、`result/` は変わらない。
- 実行(リポジトリのルートで。`--smoke` で通してから、`run.py`・`params.py`・`inputs.sha256` と変えたコードをコミットして本実行):

```bash
docker compose exec research-template uv run python projects/<study>/experiments/NNN_<slug>/run.py --smoke
docker compose exec research-template uv run python projects/<study>/experiments/NNN_<slug>/run.py
```
