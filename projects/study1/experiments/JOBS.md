# 長時間ジョブ台帳(study1)

HPC・クラウド・ローカルを問わず、このスタディの長時間または高コストのジョブを1ジョブ1行で記録します。**投入した直後に**行を足し、終わったら結果を追記します。状態と履歴はここだけに書き、`STATE.md` には実行中のジョブの確認方法と結果の記録先だけを置きます。

- 行は消さず、書き換えない(訂正は新しい行と備考で)。失敗もそのまま残す。
- 結論は `NNN_<slug>/summary.md`、経緯は同じ実験の `README.md` と `docs/research-log.md` へ。
- `docker compose exec` で動かした実行は、コンテナを作り直す(`make up` など)と止まり、記録 `out/params_used.json` は `running` のまま残る(次の実行が片づける)。作り直す前に、この表と `docker compose top` で動いているジョブがないことを確かめる。
