# 研究ログを書く

博士論文の水準の判断と行き止まりを `docs/research-log.md` に記録する。現在の状態と次の作業は
`write-handoff` スキルで `STATE.md` に書く。こちらは**何を試し、何が分かり、なぜそう判断したか**の記録。

使うとき: 章の構成を決めた、根拠にする研究を選んだ、研究の更新で結論が変わった、指導教員・審査員の指摘への
対応を決めた、行き詰まった、ユーザーが「ログに残して」と言った。

**ここに書かないもの**: 実験・解析の結果とその判断(方法の選択、データの除外、結果の撤回・訂正)の正本は研究
リポジトリの記録。そこへは書き込まず(そのリポジトリのセッションで書く)、ここには `<repo>@<sha>:<path>` で示す。

## 手順

1. **下書きを作る。** `git log --oneline -5` と会話を振り返り、次の形で書く。

   ```markdown
   ## YYYY-MM-DD — <短い題>

   - **目的**: 何をしようとしたか
   - **やったこと**: 実際にやったこと(章、研究 `projects/<id>`、`<repo>@<sha>`、関連コミット)
   - **判断**: 下した判断とその理由
   - **行き止まり**: うまくいかなかったことと原因
   - **次**: 次にやること
   ```

   あわせて次の2種類を拾い出す。
   - **繰り返さない行き止まり** → `docs/guardrails.md` の「新しい証拠なしに繰り返さないこと」の1行(研究の `id`、
     パターン、何が起きたか、証拠、再訪の条件)
   - **撤回した主張**(送った版・投稿・発表で外に出た主張を取り下げた・直した。研究リポジトリで撤回・訂正された
     結果に頼っていたものも) → `docs/guardrails.md` の「撤回した主張」の1行(根拠に `<repo>@<sha>`)

2. **ユーザーに確かめる(必須)。** ログの下書きと guardrails.md に書く行を一緒に示す。**確かめずに書き込まない**。

3. **書き込む。** `docs/research-log.md` の `<!-- newest entry below -->` の**直下**に入れる(新しい順)。
   guardrails.md の行も書く。撤回した主張を使う章・要旨・結論があれば、直す必要を報告し `STATE.md` の次の作業に
   P0 で書く。

4. **重要な決定は意思決定記録に。** 章の構成、根拠にする研究の選択、発表版と違う値を使う判断など影響の大きい
   決定は、`docs/decisions/_adr-template.md` を写して `docs/decisions/NNNN-<slug>.md`(次の連番)を作り、ログから
   リンクする。

5. **報告する。** 書き込んだファイルのパスを示す。状態が変わったなら `write-handoff` スキルで `STATE.md` も更新する。
