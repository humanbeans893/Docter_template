# 手で作った図の台帳(draft/figures/)

このディレクトリには、コードから生成できない図だけを置きます。模式図、研究の枠組みの図、写真、手描きの図、装置の図などです。

解析の図はここに置きません。スタディのコードが `save_figure`(過去の画像しか残っていない図は `import_figure`)で `projects/<study>/result/figures/` に書き出し、原稿はそこから直接読みます。解析の図をここへ写すと、由来の記録(`<name>.provenance.json`)を迂回してしまいます。

## 決まり

- 図を足したら、同じ変更で下の表に1行足します。`make check` は、ここにあるのに表の1列目に無いファイルを警告します(W11)。
- 表の1列目には、ファイル名を拡張子付きで書きます(例: `introduction-framework.pdf`)。
- ファイル名は、使う章やスタディを頭に付けます(例: `introduction-framework.pdf`、`study1-site-map.pdf`)。図の名前は、すべての図の置き場所で一つの名前空間を共有します。
- 拡張子なしで参照するので、同じ名前で拡張子だけ違うファイル(`x.pdf` と `x.png`)を置かないでください(`.pdf` が優先されます)。
- できるだけベクター形式の PDF にし、1ファイル 1 MB 以下に保ちます(リポジトリは 1 MB を超えるファイルを受け付けません)。写真は解像度を落としてから置きます。
- 編集用の元ファイル(`.svg`、`.drawio`、`.pptx` など)は `draft/figures/src/` に置き、表の「元ファイル・作成方法」の欄にその場所を書きます。
- 他者の図・写真を使う場合は、出典を図の説明文で引用し、ライセンスか転載の許諾を表に書きます。許諾の書類そのものはコミットしません。
