# 手で作った図の台帳(draft/figures/)

ここには博士論文のために手で作った図だけを置きます。模式図、研究の枠組みの図、写真、装置の図などです。

研究の結果の図はここに置きません。研究リポジトリから `projects/<id>/figures/` に写し、章からは `\includegraphics{<id>/figures/<name>}` で読みます(元はその研究のカード `projects/<id>/README.md` に書きます)。

## 決まり

- 図を足したら、同じ変更で下の表に1行足します。`make check` は、ここにあるのに表の1列目に無いファイルを警告します(W11)。
- 表の1列目には、ファイル名を拡張子付きで書きます(例: `introduction-framework.pdf`)。
- ファイル名は使う章を頭に付けます(例: `introduction-framework.pdf`)。本文では拡張子なしで参照するので、同じ名前で拡張子だけ違うファイル(`x.pdf` と `x.png`)を置かないでください。
- できるだけベクター形式の PDF にし、1ファイル 1 MB 以下に保ちます。写真は解像度を落としてから置きます。
- 編集用の元ファイル(`.svg`、`.drawio`、`.pptx` など)は `draft/figures/src/` に置き、表の「元ファイル・作成方法」に場所を書きます。
- 他者の図・写真を使う場合は、出典を図の説明文で引用し、ライセンスか転載の許諾を表に書きます。許諾の書類そのものはコミットしません。
