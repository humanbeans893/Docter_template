# 提出前の確認項目

大学・研究科の最新の提出要項を正とします。この一覧は一般的な項目だけです。

## 書式

- [ ] 正式な題目(和英)、著者名、学位名、大学・研究科・専攻、指導教員、提出日、キーワード(`thesis-config.tex`)
- [ ] 表紙・審査用の表紙に指定の様式があれば、`frontmatter/titlepage.tex` をそれに合わせた
- [ ] 用紙、余白、行間、片面・両面、文字の大きさ、ページ番号、要旨の字数(`thesis-config.tex`)
- [ ] 業績一覧・宣誓文・略語・記号のページの要否(`thesis-config.tex` のフラグ)と、雛形の文が残っていない
- [ ] 電子提出のファイル名、容量、PDF/A、暗号化の禁止などの要件

## 内容と誠実さ

- [ ] 論文を基にした章の前書き(出版の状況、著者の貢献、転載の許諾、発表版との違い)と、業績一覧・`research.json` の `paper`・`paper_status` が一致している
- [ ] 出版社の規程で学位論文への再利用が許され、他者の図・写真は転載の許諾がある
- [ ] 本文・要旨・結論の数値がすべて `\val` で、`projects/<id>/values.tex` の元(研究リポジトリのコミット、論文の表)をたどれる
- [ ] 各研究の `research.json` の `source` が使った研究リポジトリのコミットを指し、撤回・訂正された結果を使っていない(`docs/guardrails.md`)
- [ ] 手で作った図がすべて `figures/README.md` の台帳にあり、出典とライセンスが書いてある
- [ ] 研究倫理の承認番号、同意、データの利用許諾、利益相反、資金提供と助成番号(謝辞)

## 書誌

- [ ] `reference.bib` の全項目を DOI(無ければ ISBN か公式ページ)で原典と照合し、`verified` の欄がある
- [ ] 雛形の `lamport1994latex` と `main.tex` の `\nocite` を消した

## 技術的な検証

- [ ] `make test && make lint`
- [ ] `make submission` が誤り 0(提出用の PDF と補足資料を作り、`make check-final` で2つを合わせて検査する)
- [ ] `make security-history`
- [ ] PDF を別の端末で開き、目次のリンク、フォント、図表、ページの順序と番号を確かめた

## 保存

- [ ] 提出する版のコミットにタグを付け、`make archive TAG=<タグ>` で `dist/<タグ>/`(PDF、ソース、チェックサム)を作った
